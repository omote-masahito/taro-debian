# jwd (ジャストシステム改造版 Wine) の変更は現行 Wine にどこまで入っているか

一太郎 for Linux 付属の `Wine-20031212.tar.gz` (素の Wine) と `wine.tar.gz` (jwd-20041221)、`ChangeLog.jwd` を、
Wine 10.0 (Debian 13) と上流の現行ツリー (Wine 11.21、2026-11-10 時点) のソースと突き合わせた。
一部は Wine 10.0 上で小さな検査プログラム ([`tools/jwd-probe.c`](../tools/jwd-probe.c)) と一太郎本体を動かして実測した。

## 結論

- **大半の領域は、現行 Wine が別実装で同等以上の機能を持っている。** 構造化ストレージ、クリップボード、
  リッチエディット、IME の未確定文字列表示、メモリ量の丸めなどは、jwd が手を入れた理由そのものが解消している。
- **ただし jwd のパッチが取り込まれたわけではない。** 現行コードは全面的に書き直されており、
  「同じ修正が入っている」と一対一で言える項目はわずかしかない。
- **未反映と確認できたものが 6 件ある。** うち 4 件は Wine 10.0 上で症状を再現した。いずれも一太郎の
  付属フォントや日本語固有の文字に関わるもので、検証で最初に当たりそうな箇所。
- **コントロールやウィンドウ管理の細かい挙動修正 (約 280 件) は静的には判定できない。** ここは実機で
  一太郎を操作して拾うしかない。

## jwd の変更の規模

| 項目 | 値 |
|---|---|
| ChangeLog のエントリ | 620 件 (2003-08-04 〜 2004-12-17) |
| 変更されたファイル | 167 個 |
| 追加されたファイル | 30 個 (ディレクトリ単位のものを含む) |
| 既存ファイルへの追加・変更 | 約 1.56 万行 |
| 追加された `dlls/ole32/*.cpp, *.h` | 約 9,000 行 (独自の複合文書実装) |

ChangeLog のエントリ数が多いモジュール: x11drv 155 (うち XIM/ATOK 関連 60)、winhelp 69、comctl32 61、
windows 54、gdi 53、controls 52、ole32 47、shell32 24、user 23、objects 17。

## 未反映と確認できたもの

| # | jwd の変更 | 現行 Wine の状態 | 確認方法 | 一太郎での影響 |
|---|---|---|---|---|
| 1 | `int21.c`: AX=73xx の未実装ファンクションでキャリーを立てる (2004-02-04) | 10.0 / 11.21 とも `INT21_Fat32` の default はキャリーを立てずに成功で戻る | ソース + 実測 | Windows 98 / Me として動かすとセットアップが空き容量チェックでゼロ除算。XP / 2000 なら通らない経路 |
| 2 | `freetype.c`: OS/2 テーブルが version 0 で最終文字が U+FF60 以上なら SHIFTJIS とみなす (2004-07-01) | version 0 は LATIN1 か SYMBOL に固定 | ソース + 実測 | ＪＳゴシック / ＪＳＰゴシックが charset=0 で列挙され、SHIFTJIS 指定で作ると別のフォント (検証環境では IPAゴシック) に置き換わる |
| 3 | `freetype.c`: `mort` テーブルによる縦書き用グリフ置換 (2004-01-30) | 縦書き置換は GSUB の `vrt2` / `vert` のみ。`mort` の参照なし | ソース | 付属フォントのうち JL 系は GSUB `vert` を持つが、JS 系・DF 系は `mort` しか持たない。縦書きで句読点や長音が縦用字形にならない見込み (表示は未実測) |
| 4 | UTF-8 と MS932 で対応の異なる文字 (〜 − など) の変換 (2004-09 〜 11、`clipboard.c`, `utf8.c`) | 特別扱いなし。U+301C, U+2212, U+2016, U+2014 は CP932 に変換できない | 実測 | Linux 側アプリからコピーした「〜」「−」を一太郎に貼ると □ になる (同時に貼った「‖」「—」は表示された。CF_TEXT で受け取るアプリでは 4 文字とも「?」になる) |
| 5 | `file.c`: 読み取り専用かどうかをプロセスの UID / GID で判定 (2004-06-11) | 所有者・グループ・その他のどれにも書き込みビットが無いときだけ READONLY | ソース + 実測 | 他人が所有する 644 のファイルが READONLY=0 と報告され、書き込みオープンは失敗する。jwd の ChangeLog にある「上書き保存時に保存先ダイアログが出る」と同じ条件 |
| 6 | SMlib による X セッション管理 (ログアウト時に未保存文書を確認、2004-12) | winex11 に SMlib の利用なし | ソース | ログアウト時に確認なしで終了する可能性 (未実測) |

2 の補足: 同じ検査で ＪＳ平成明朝体W3 は charset=134 (GB2312) と報告された。このフォントは OS/2 version 1 で
日本語のコードページビットが立っていない。jwd の修正対象 (version 0) とは別の条件で、Windows での扱いは未確認。

## 静的には判定できないもの

次の領域は、個別の表示・フォーカス・再描画の不具合を一つずつ直した記録で、最初の 3 つだけで約 280 件ある。
現行 Wine の該当コードは構造ごと変わっているので、ソースを比べても「直っているか」は分からない。

- comctl32 (61 件): リストビューが大半。ファイル一覧の列幅変更、名前変更、スクロール、選択表示など。
- controls / windows / user (約 130 件): メニューのトラッキング、MDI 子ウィンドウ、ダイアログのフォーカス、
  コンボボックスのドロップダウン、クリップボード所有者の管理など。
- x11drv の IM 以外 (95 件): ウィンドウマネージャとの連携 (最大化、フローティング、ツールウィンドウ)、
  マウス・キーリピート、再描画。
- winhelp の表示の細部 (インデント、ビットマップ、ポップアップの位置とサイズ)。
- gdi の個別修正: DF 系フォントの点数 1 の曲線データ、中抜き斜体の文字切れ、`MM_ANISOTROPIC` での変形など。

ChangeLog の文面に出てくる画面 (ナレッジウィンドウ、ファイラ、簡易用紙変更ダイアログ、ESC メニュー、
ビジネス単語一覧、グラフのデータ編集) は、当時ジャストシステムが不具合を踏んだ場所なので、検証の道順として使える。

## 対象外のもの

- **ATOK X との連携** (x11drv の `xim.c`, `immwin.c`, `himc.c`、60 件): ATOK X 固有の挙動に合わせた調整。
  現行 Wine は XIM を一般的に扱う実装で、比較の対象にならない。
- **マルチユーザー対応** (`misc/registry.c`, `server/registry.c`, `env/`): root がシステムのレジストリを書き、
  各ユーザーは `user.reg` だけを持つという jwd 独自の配置。現行 Wine はプレフィックス単位。
- **起動引数のパス変換** (`set_argv_path`、`file://` と URL エンコードへの対応): 現行 Wine は引数を
  変換しない。A 経路ではランチャが `winepath -w` で変換している。
- **jwd 専用のツールと設定**: `winehpt`、`tools/e2j`、`libs/wine/url.c`、`system.conf` / `user.conf`。

## 検証で先に見るとよい箇所

1. **フォント選択で ＪＳゴシック / ＪＳＰゴシックを指定した文書。** 表示と印刷が別フォントになっていないか (上記 2)。
2. **縦書き文書を JS 系・DF 系フォントで。** 「、。ー「」」が縦用の字形と位置になるか (上記 3)。JL 系と比べると分かりやすい。
3. **Linux 側アプリとのコピー & ペースト。** 「〜 − ‖ —」を含む文字列の往復 (上記 4)。
4. **他人が所有するファイル、読み取り専用のファイルを開いて上書き保存。** (上記 5)
5. **印刷。** jwd は wineps に用紙サイズ周りの回避策を入れている (ユーザー定義用紙を常に有効にするなど)。未検証。
6. **ダイアログの [ヘルプ] ボタンとポップアップヘルプ。** 先頭ページ以外は未検証。

## 調べ方と限界

- 差分は `diff -r` による。ChangeLog は 620 件すべてに目を通し、モジュールと主題で分類した。
- 「ソース」とあるものは、Wine 10.0 と 11.21 の両方で該当する実装の有無を確認したもの。動作は見ていない。
- 「実測」とあるものは、Debian 13.7 のユーザーランド上の Wine 10.0 (32bit プレフィックス、Windows XP として動作)
  で確認したもの。Wine 11.21 は動かしていない。
- 実 Windows との比較はしていない。「Windows と違う」という判断は jwd の ChangeLog の記述に依っている。
- 「反映済み」は機能が存在することの確認であり、jwd が直した個々の不具合が再現しないことの確認ではない。
